3. How to read the results

  • Speed. In this pure-Python code RC4 is fastest (one swap and one XOR per byte), then AES, then DES. DES is slowest even though its key is shorter: it runs 16 rounds on 8-byte blocks, so it needs twice as many block operations as AES per byte, and its bit permutations are expensive in software. With hardware AES instructions (AES-NI, found in modern CPUs) AES is usually the fastest of the three, so this ranking is a property of the implementation, not only of the ciphers.
  • Size. AES and DES are block ciphers in CBC mode: PKCS#7 padding adds 1-16 bytes (AES) or 1-8 bytes (DES). RC4 is a stream cipher, so its ciphertext is exactly as long as the plaintext. The IV is 16 bytes for AES, 8 for DES (one block); RC4 uses a 16-byte nonce to get a fresh key per message.
  • Content. The three ciphertexts of the same file share no visible pattern, and all have an entropy close to 8 bits per byte, so they look like random data. Encrypting the same file again would give different ciphertexts again, because the IV/nonce is random.
  • Security, which timing does not show. Only AES is a secure choice: DES has a 56-bit key that can be brute-forced, and RC4 has biased output and is banned from TLS (RFC 7465). The app reads your data from the AES copy; the other copies exist for this comparison.
