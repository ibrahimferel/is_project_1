RC4 stream cipher

Educational only. RC4 is broken and prohibited in TLS (RFC 7465).

RC4 turns the key into a keystream and XORs it with the data. Here both messages are encrypted with the same key, a classic mistake, to show what an attacker gains.

1. Key-scheduling algorithm (KSA)

S starts as 0, 1, ..., 255. For i = 0..255: j = (j + S[i] + key[i mod keylen]) mod 256, then swap S[i] and S[j]. The result is a key-dependent permutation:

2. Keystream generation (PRGA)

Each step: i = i + 1, j = j + S[i], swap S[i] and S[j], output S[S[i] + S[j]] (all mod 256).
