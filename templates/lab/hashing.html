Hashing vs encryption

Password hashing

One-way. The server stores the hash and, at login, hashes the typed password again and compares. It never needs, and cannot recover, the original.

Encryption

Two-way. Anyone with the key gets the plaintext back. Right for files and personal data the user must read again, wrong for passwords.
